# دليل لوحة تحكم لمسة

## الدخول المحلي

- الرابط: `http://127.0.0.1:8000/admin`
- البريد: `admin@lams-event.local`
- كلمة المرور: `LocalOnly!2026`

هذا الحساب للاختبار المحلي فقط، والـSeeder يرفض إنشاءه خارج `APP_ENV=local`.

## إدارة المحتوى

من القائمة الجانبية يمكن إدارة المقالات والخدمات وتصنيفاتها والمناطق والصفحات
والمعارض. يتضمن النموذج:

- العنوان والملخص وكتل المحتوى المنظمة.
- حالة مسودة/منشور وتاريخ النشر.
- الصورة البارزة والترتيب والمحتوى المميز.
- الأسئلة الشائعة.
- عنوان SEO والوصف وCanonical وOpen Graph وTwitter وJSON-LD.

المحرر لا يرى خيار النشر. مدير المحتوى يستطيع النشر، ومدير النظام يدير
المستخدمين والأدوار.

## الصور

تقبل المكتبة JPEG وPNG وWebP فقط، بحد 8MB والحدود المحددة للأبعاد والبكسلات.
يفحص الخادم MIME الحقيقي، يولد اسمًا عشوائيًا ونسخة WebP، ويحفظ الأبعاد
والـSHA-256 والنص البديل. لا تعتمد الحماية على امتداد اسم الملف.

## تغيير الرابط

لا تعدل slug المنشور مباشرة. افتح السجل واختر «تغيير الرابط مع تحويل 301»،
ثم أدخل slug لاتينيًا. تتحقق العملية من عدم وجود تعارض أو حلقة وتحدث بيانات
SEO وsitemap. راجع قسم «تحويلات الروابط» بعد العملية.

## بقية الأقسام

- «القوائم»: ترتيب روابط الهيدر والفوتر.
- «بيانات التواصل»: الهاتف وواتساب والبريد والشبكات.
- «إعدادات الموقع وSEO»: القيم العامة المنظمة.
- «خريطة الموقع»: Metadata فقط؛ المسارات الموروثة مقفلة.
- «سجل النشر»: حالة snapshots وأسباب الفشل.
- «سجل التدقيق»: الدخول والتعديلات الحساسة وعناوين IP.
